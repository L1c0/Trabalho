# Houseki — os quatro Shorts, texto de gravação

Grava os quatro na mesma sessão, mesma voz, mesmo microfone, mesma
distância. Se gravar em dias diferentes o timbre muda e dá trabalho
emendar depois.

**Ritmo:** um pouco mais rápido que o ensaio, mas não muito. Short não é
locução de anúncio. A diferença é que aqui não tem pausa longa — cada
`//` é um respiro curto, de meio segundo, não os dois segundos do ensaio.

**A última frase de cada um é uma pergunta.** Lê ela mais devagar que o
resto e deixa morrer. É ela que fica na tela até o fim e volta no loop.

Fala tudo direto, sem anunciar número de Short, sem "fala galera". Eu
corto e separo aqui.

---

## 1 · O LEVIATÃ — cerca de 40 segundos

Olha essa gravura de 1651. É a capa do Leviatã, do Thomas Hobbes. //

Um gigante coroado sobre uma cidade, com uma espada numa mão e um báculo
na outra. //

Agora chega perto. //

O corpo dele inteiro é feito de gente. Centenas de pessoas pequenas, de
costas, olhando para a cabeça. //

Nenhuma delas é o gigante. Juntas, são. //

Quatro anos depois dessa gravura, o mesmo Hobbes escreveu a versão mais
cruel do paradoxo do Navio de Teseu. //

Faz sentido. Ele passou a vida pensando em coisas feitas de partes. //

Quantas pessoas você consegue contar aí?

---

## 2 · O NAVIO — cerca de 45 segundos

Esse navio não tem nenhuma peça original. E ainda assim pode ser o mesmo
navio. //

Os atenienses guardaram o navio em que Teseu voltou de Creta, como
monumento. Só que madeira apodrece. Cada tábua estragada eles trocavam
por uma nova. //

Até não sobrar nenhuma das originais. //

E os filósofos gregos se dividiram em dois grupos. Uns diziam que
continuava sendo o mesmo navio. Outros, que já era outra coisa usando o
mesmo nome. //

Mil e seiscentos anos depois, Thomas Hobbes piorou tudo. E se alguém
tivesse recolhido cada tábua velha e montado um segundo navio com elas? //

Um tem a forma. O outro tem a matéria. //

Qual dos dois é o navio de Teseu? //

Não existe resposta certa. Existe escolha sobre o que você acha que faz
uma coisa ser ela mesma. //

Qual dos dois você acha que é o navio?

---

## 3 · A MEMÓRIA — cerca de 45 segundos

Nesse mangá a memória não fica no cérebro. Fica na pedra de que o corpo é
feito. //

A protagonista é uma gema. Quando ela perde uma parte do corpo numa luta,
colocam outra no lugar, de outro mineral. //

E a lembrança que estava ali vai embora junto com a peça antiga. //

Ela perdeu as pernas. Esqueceu uma amiga. //

Perdeu os braços. Perdeu a cabeça inteira. Perdeu os dois olhos. //

Cada troca levou um pedaço do passado dela. //

No fim, o que sobrou do corpo original é um torso. //

E a pergunta que o mangá nunca faz em voz alta: em que momento ela parou
de ser ela? //

Se você esquecesse tudo, ainda seria você?

> As três frases da sequência de perdas — pernas, braços, cabeça, olhos —
> vão **mais rápido** que o resto, quase atropelando. É de propósito: as
> perdas acumulam rápido demais pra processar. Aí você para seco antes de
> "cada troca levou um pedaço".

---

## 4 · A PEDRA — cerca de 35 segundos

A autora escolheu, para a protagonista de um mangá sobre perder o corpo
pedaço por pedaço, a pedra mais frágil que existe. //

Fosfofilita. Dureza três e meio na escala Mohs. //

Diamante é dez, o máximo. //

Colecionador trata espécime de fosfofilita como se fosse de vidro. //

E os melhores cristais vieram de uma mina em Potosí, na Bolívia, que não
produz mais. O que existe é o que já foi tirado. //

Ela não escolheu uma pedra bonita para protagonista. //

Escolheu uma que quebra se você olhar com força. //

Que outra obra esconde ciência de verdade assim?

## Depois de gravar

Manda o arquivo cru, sem tratar nada. Eu corto os quatro, normalizo em
−16 LUFS, ponho o leito de sala e a trilha, e devolvo pronto pra montar.

**Uma correção no projeto:** o `SHORTS.md` manda a legenda queimada em
Cormorant. **Troca por EB Garamond.** O build da Cormorant põe o acento
agudo e o circunflexo acima da altura de maiúscula — no ensaio quase não
dava pra ver, mas legenda queimada a 64px, em português, palavra por
palavra, no meio da tela, o defeito vai aparecer em todo "é", "você" e
"memória". Foi por isso que eu troquei a fonte no Vinland.
